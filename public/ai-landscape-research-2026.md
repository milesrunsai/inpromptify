## 5. KEY TRENDS FOR ASSESSMENT QUESTIONS

### Architecture Decisions Professionals Must Know
1. **Test-time compute / "thinking" models** — All major providers now offer extended thinking (Claude), thinking mode (Gemini), reasoning (GPT o-series). When to use vs. standard inference.
2. **Multi-model routing** — GPT-5 uses internal routing. Enterprises should route cheap→expensive. GPT-5.4 nano for classification, Opus 4.7 for complex reasoning.
3. **Context window strategy** — Llama 4 Scout: 10M tokens. Gemini 3.1 Pro: 10M tokens. Claude: 1M. Knowing when massive context helps vs. when RAG is better.
4. **Open-source vs. API tradeoffs** — Llama 4, DeepSeek, Gemma for on-premise/data sovereignty. API for convenience and latest capabilities.
5. **Agentic coding** — Claude dominates (87.6% SWE-bench). Cursor + Claude Code = developer stack. But GPT-5.3 Codex has 0.003s latency.
6. **Cost-per-task analysis** — Claude Sonnet 4.5: $0.56/task at 70.6% SWE-bench. GPT-5 mini: $0.04/task at 59.8%. 14x cost difference for 10% quality delta.

### What Separates Good from Great AI Professionals
- **Good:** Knows ChatGPT exists, can write basic prompts
- **Great:** Knows GPT-5.4 nano is 12.5x cheaper than GPT-5.4 for the same classification task
- **Good:** Uses one model for everything
- **Great:** Routes to Haiku for chat, Sonnet for code review, Opus for complex architecture
- **Good:** Fine-tunes a model for every problem
- **Great:** Knows RAG is better for factual retrieval, fine-tuning for style/behavior, few-shot for quick prototyping
- **Good:** Copies prompts from the internet
- **Great:** Engineers system prompts with anti-hallucination constraints, output format specifications, and evaluation criteria
